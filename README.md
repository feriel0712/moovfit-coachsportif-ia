# moovfit-coachsportif-ia
MoovFit is an Android fitness app that uses ML Kit Pose Detection to track exercises via camera in real-time. It counts reps using K-NN classification with EMA smoothing, identifies 10+ poses (squats, push-ups, yoga, lunges), saves history with Room DB, and shows weekly progress charts. Optional Python FastAPI backend for server-side AI processing.
